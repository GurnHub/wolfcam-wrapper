**Alpha release.** Third build of WolfDeck. It fixes playing a frag from the Frag finder with Quake Live (`.dm_91`) demos, and stops the free camera zooming with the demo taker. Bug reports are welcome as GitHub issues.

WolfDeck is a desktop front end for [WolfcamQL](https://github.com/brugal/wolfcamql), the Quake Live / Quake 3 demo player, and a replacement for Wolf Whisperer. It does not include WolfcamQL; it starts the copy you already have.

## Fixed

- **Playing a frag from the Frag finder started at the beginning of the demo** ([#6](https://github.com/GurnHub/wolfcam-wrapper/issues/6)). With `.dm_91` demos, WolfcamQL checks the demo's Steam Workshop items before it loads the demo. WolfDeck's start-up commands (the jump to the frag, the player to follow, the profile's extra commands) ran during that check and were lost. They now wait until the demo has loaded. Renders start the same way, so a render of a `.dm_91` demo could also start at the wrong time; that is fixed too.
- **The free camera zoomed in and out with the demo taker** ([#7](https://github.com/GurnHub/wolfcam-wrapper/issues/7)). WolfcamQL does this when its `cg_useDemoFov` setting is 2, for example when it is saved in your WolfcamQL config. WolfDeck now sets it to 0 unless the profile chooses otherwise.

## New

- **Config → View → Demo taker's field of view** (`cg_useDemoFov`): ignore it, use the demo taker's field of view, or follow their zoom. The last option also zooms the free camera.

## Download

| System | File |
| --- | --- |
| Windows 10/11 | `WolfDeck_0.1.0_x64-setup.exe` |
| Linux | `WolfDeck_0.1.0_amd64.AppImage`, or `WolfDeck_0.1.0_amd64.deb` for Debian/Ubuntu |

`SHA256SUMS.txt` lists the checksums. Inside the app the version still shows as 0.1.0. Installing over an earlier alpha keeps your settings, profiles and clips.

The Windows installer is not code-signed, so SmartScreen may say "Windows protected your PC". Choose *More info*, then *Run anyway*.

WolfDeck supports Windows and Linux only; there is no macOS build.

## Requirements

- WolfcamQL 12 or newer, with the Quake Live pak files in its `baseq3` (WolfDeck can copy them from your Quake Live install).
- ffmpeg, only for encoding renders to MP4/MOV/MKV.

## Not yet verified

- **Live control on Windows.** The Player's buttons reach WolfcamQL through a key press (F13 by default, changeable in Settings). This has not been tested on a real Windows machine yet. Launching demos and batch rendering do not depend on it.
- **These fixes on Windows itself.** They were tested on Linux with WolfcamQL built from source and with real `.dm_91` demos, but not in the Windows app.
- **`.dm_90` demos** are decoded according to the WolfcamQL source, but no sample files were available for testing. `.dm_91` demos are now tested with real files.
